# プロジェクトドキュメント参照ルール

このプロジェクトは DuckDB を使って GUI からローカルファイルに対して SQL を実行できる Python デスクトップアプリです。

## 起動時の必須アクション

チャット起動時（セッションの最初のタスクに着手する前）に、以下のドキュメントを必ず読み込んで、仕様・使い方・ビルド手順を把握すること。

- `documents/features.md` — 全機能の一覧と説明
- `documents/usage.md` — 画面構成・操作手順・ショートカット
- `documents/build.md` — exe化の手順・配布フォルダ構成

## 運用ルール

- 機能や仕様に関する質問・実装作業を行う際は、上記ドキュメントを一次情報として参照すること。
- 機能を追加・変更した場合は、対応するドキュメント（`documents/` 配下）も更新すること。
- ドキュメントとソースコード（`src/duckdbui/main.py`）の記述が食い違う場合は、ソースコードを事実として扱い、フミに相違点を報告すること。
