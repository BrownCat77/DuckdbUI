# DuckDB SQL Editor - 使い方

## 起動方法

```bash
uv run duckdbui
```

## 基本的な使い方

### 1. ファイルを読み込む

左サイドバーの **TABLES** エリアに Parquet / CSV / JSON ファイルをドラッグ&ドロップします。

- 複数ファイルを同時にドロップできます
- ファイルはコピーされず、元ファイルへの参照（VIEW）として登録されます
- Windowsエクスプローラーからのドロップに対応しています

#### フォルダをドロップした場合

フォルダをドロップすると **VIEW作成ウィンドウ** が開きます。以下を指定して「作成」ボタンを押すとVIEWが作成されます。

| 項目 | 説明 |
|------|------|
| ビュー名 | 作成するVIEWの名前（初期値はフォルダ名） |
| フォーマット | `parquet` / `csv` / `json`（初期値は `parquet`） |
| ファイルパス | 読み込み対象のパス（初期値はドロップしたフォルダ配下の `*.parquet`） |

フォーマットのドロップダウンを切り替えると、ファイルパス末尾の `*.parquet` が選択したフォーマット（`*.csv` / `*.json`）に自動で追従します。ファイルパスを手動で書き換えた場合はその内容が優先されます。

ファイルパスの末尾に `/*.parquet` のようなワイルドカードを付けると、フォルダ配下の複数ファイルをまとめて1つのVIEWとして読み込めます。

### 2. SQLを実行する

エディタにSQLを入力して実行します。

```sql
SELECT * FROM your_file
```

実行方法：
- `Ctrl+Enter` キー
- 「▶ 実行」ボタン

テーブル名をダブルクリックすると `SELECT * FROM テーブル名` が自動入力されて即実行されます。

### 複数のクエリをタブで扱う

中央エリア上部のタブで、複数のクエリと結果を切り替えながら作業できます。データの比較などに便利です。

- 各タブは **SQLエディタの内容と実行結果を個別に保持** します
- タブバー右端の **「＋」** で新しいタブを追加します（タブ名は「クエリ1」「クエリ2」…と連番）
- 各タブの **「✕」** でタブを閉じます（最後の1枚は閉じられず、内容がクリアされます）
- タブを **ドラッグ&ドロップ** すると順序を入れ替えられます
- タブを **ダブルクリック** するとタブ名を変更できます

DB接続・テーブル一覧・保存済みクエリは全タブで共通です。エクスポートは現在アクティブなタブの結果が対象になります。

### 3. テーブルをフォルダで整理する

テーブル/VIEWが増えてきたら、左サイドバーのフォルダでグループ分けして整理できます。フォルダは表示上のグループ分けだけで、テーブルの中身やDuckDBのschemaには影響しません。

- **フォルダを作る**: TABLESヘッダー右の **「🗀＋」** ボタンを押し、フォルダ名を入力します
- **フォルダに入れる**: テーブル/VIEWをドラッグして、目的のフォルダの見出し行へドロップします
- **フォルダから出す**: テーブル/VIEWをフォルダより上のルート領域へドラッグすると、フォルダ無しに戻ります
- **開閉する**: フォルダの見出しをクリックすると開閉します（`▾` 展開 / `▸` 折りたたみ）。開閉状態は保存され、次回起動時に復元されます
- **名前を変える**: フォルダの見出しをダブルクリックします
- **削除する**: フォルダ見出しの **「✕」** で削除します。中のテーブルはフォルダ無しに戻り、テーブル自体は消えません

フォルダ構成はDBファイルごとに `db-files/<DB名>.folders.json` に保存され、DBを切り替えると自動で読み込まれます。

### 4. 結果を確認する

クエリ結果は下部のテーブルに表示されます。

- 1ページ100件表示
- `◀` / `▶` ボタンでページ移動
- `1-100 / 914件 (1/10ページ)` のように件数を確認できます

### 5. 結果をエクスポートする

クエリ実行後、ボタンバー右側のエクスポートボタンが有効になります。

| ボタン | 形式 |
|--------|------|
| CSV | UTF-8 BOM付きCSV |
| JSON | JSON配列 |
| Parquet | Parquet形式 |

保存ダイアログの初期ファイル名は `20260328_161800.csv` のような日時形式です。

## DBファイルの管理

### 新しいDBを作成する

1. ヘッダーの「新規作成」ボタンをクリック
2. DBファイル名を入力（`.duckdb` は自動付与）
3. `db-files/` フォルダにファイルが作成され、自動的に切り替わります

### DBを切り替える

ヘッダーのドロップダウンからDBを選択します。切り替えると：
- テーブル一覧がそのDBの内容に更新されます
- 保存済みクエリもそのDBに紐づいたものに切り替わります

### インメモリモード

デフォルトの `(インメモリ)` はアプリを閉じるとデータが消えます。一時的な分析作業に使用してください。

## クエリの保存と管理

### クエリを保存する

1. エディタにSQLを入力
2. 「保存」ボタンをクリック
3. 右サイドバーの **SAVED QUERIES** に追加されます

### 保存済みクエリを使う

- **クリック**: エディタにSQLを展開
- **ホバー**: SQL全文をツールチップで確認
- **ドラッグ**: 上下にドラッグして順序を並び替え
- **✕**: クエリを削除

### 保存場所

保存済みクエリ・フォルダ構成はDBごとに `db-files/` フォルダに保存されます。

```
db-files/
├── mydata.duckdb              # DBファイル
├── mydata.duckdb.queries.json # mydata用の保存クエリ
├── mydata.duckdb.folders.json # mydata用のフォルダ構成
├── _inmemory.queries.json     # インメモリ用の保存クエリ
└── _inmemory.folders.json     # インメモリ用のフォルダ構成
```

## テーブル情報を確認する

テーブル一覧のテーブル名にマウスをホバーするとツールチップが表示されます。

- **VIEW**: SQL定義（`CREATE VIEW ...`）
- **テーブル**: カラム名と型の一覧
